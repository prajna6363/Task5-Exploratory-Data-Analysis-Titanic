# Titanic Dataset – Exploratory Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Titanic dataset using Python. The analysis explores passenger characteristics, missing values, distributions, correlations, and factors associated with survival.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

The dataset contains 891 passenger records and 12 original features, including passenger class, gender, age, fare, and survival status.

## Analysis Performed

- Dataset overview using `info()` and `describe()`
- Missing value analysis
- Duplicate record check
- Data cleaning
- Value count analysis
- Categorical data visualization
- Histograms
- Boxplots
- Scatterplots
- Correlation heatmap
- Pairplot
- Key findings and conclusions

## Key Findings

- 342 passengers survived and 549 did not survive.
- Female passengers had better survival outcomes than male passengers.
- First-class passengers had better survival outcomes.
- Third-class passengers had the highest number of non-survivors.
- Fare was highly right-skewed.
- Age alone showed a weaker relationship with survival.

## Files

- `Titanic_EDA.ipynb` – Complete EDA analysis
- `train.csv` – Titanic dataset
- `Titanic_EDA_Report.pdf` – Project report

## Conclusion

The analysis identified gender, passenger class, and fare as important factors associated with Titanic passenger survival. The project demonstrates the use of EDA techniques to discover patterns and insights from real-world data.
